## 自动评分（浏览器）

- **Data Lab**：使用 `vendor/browsercc` 的真实 Clang/wasm32；每个任务生成确定性边界+随机测试 harness；规则检查限制运算符/常量/控制流。13/13 任务、100/100 已用开发期参考实现验证；测试集不是官方 btest 的逐字节复刻。
- **Architecture Lab**：Part A 用 `Y86Assembler` + `Y86Subset` 检查 7 组链表；Part B 用 `Y86HCLControl` + `Y86Pipeline` 检查 iaddq；Part C 用 `ArchitectureCopy.test` 检查 ncopy 正确性与周期。三部分合计 100/100 已用开发期参考实现验证；不是官方 sim/psim 的完整复刻。
- **Malloc Lab（浏览器子集）**：`labs/malloc-harness.js` 在 wasm32 中编译学生 `mm.c`，跑 4 组 trace + 释放复用检查，按正确性/利用率/realloc 评分；首适分配器通过，浏览器得分 100/100。不是官方 mdriver，需手动采用分数。官方 mdriver 的 `Perf index = ... = NN/100` 可粘贴到实验页解析并记录。
- **Buffer Lab（浏览器 IA32 模型）**：`labs/buffer-sim.js` 用 32 位栈、4 字节返回地址与 movl 全局写模拟 Smoke/Fizz/Bang/Boom/Nitro；五关参考 payload 全部通过，60/60。作为 legacy 对照，不是官方 IA32 靶场。
- **Shell Lab（浏览器 JS 模型）**：`labs/shell-harness.js` 运行学生的 `Shell` 作业控制策略，覆盖 eval/jobs、前台等待、后台 SIGCHLD、jobs、SIGINT/SIGTSTP、bg/fg 六个场景；参考实现 100/100。不是官方 C tsh，需手动采用。
- **Proxy Lab（浏览器 JS 模型）**：`labs/proxy-harness.js` 运行学生的 `Proxy.handle`，检查基本转发、404、对象缓存、LRU 淘汰与 POST 健壮性；参考实现 100/100。不是官方 C proxy，需手动采用。 官方 `driver.sh` 的 `totalScore: NN/70` 可粘贴到实验页解析并归一化为 100 分制记录。
- **Attack Lab（浏览器模型）**：`labs/attack-sim.js` 使用固定栈布局、受限 x86 子集与符号 gadget 执行学生十六进制 payload；Touch1/2/3、Fire2/3 五关参考 payload 全部通过，浏览器得分 100/100。不是官方 ctarget/rtarget，需手动采用。
- **Performance Lab（浏览器相对性能）**：`labs/perf-harness.js` 使用官方 naive `rotate`/`smooth` 作基线，用 wasm32 编译学生实现，从 phase run 到结束计时并比较像素 hash；优化参考实现 rotate 1.34×、smooth 4.22×，浏览器得分 100/100。wasm 时间不是官方 CPE，需手动采用。
- **Cache Lab Part A/B（浏览器子集）**：`labs/cache-harness.js` 编译学生 `cache_init/cache_access`，4 组配置 × 220 次 L/S/M，参考实现 4/4 通过，Part A 40/40；`labs/transpose-harness.js` 对 `transpose_submit` 的 A/B 二维访问插桩，参考解在 32/64/61 上 miss 284/1180/1772，全部低于阈值，Part B 60/60。两者合计 100/100，需手动采用；官方 test-csim/test-trans 仍在实验机中。
