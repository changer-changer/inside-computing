# 架构

## 总览

“计算之境”是**零构建的静态 Web 应用**：HTML/CSS/经典脚本/ES Modules 直接由静态服务器提供。没有后端账号系统、数据库或上传接口；课程进度与代码草稿保存在浏览器 `localStorage`。

```text
浏览器
├─ index.html                 3D 实验台（Three.js + 课程入口）
├─ course/                    12 章课程、结业检查、学习档案
│  ├─ assets/course.js        课程壳、进度、题目、编辑器、导出
│  ├─ assets/curriculum.js    12 章 + 10 实验元数据
│  └─ content/ch01..ch12.js   章节正文与可视化初始化
├─ labs/                      实验页、内容、浏览器检查器
│  ├─ lab.html + lab-kit.js   统一实验壳
│  ├─ datalab.html/js         真实 wasm32 C 的 Data Lab
│  └─ *-harness.js            各实验的浏览器检查
├─ engine/                    模拟器、可视化模型、wasm 编译 Worker
│  ├─ c-worker.js             Clang/wasm32 编译运行 Worker
│  ├─ y86-*.js / hcl-control  Y86-64、流水线、HCL 子集
│  ├─ cache-lab / vm-* / ...  缓存、页表、进程、I/O、HTTP、并发模型
│  └─ x86-assembler.js        AT&T 子集汇编器 + Blink 用户态执行
└─ vendor/                    Three.js、browsercc、Blink、WASI shim
```

## 分层

### 1. 课程层

- `course/assets/curriculum.js`：唯一课程/实验元数据源（章节、实验、任务、分数、模式）。
- `course/chapter.html?ch=NN` 加载 `course/content/chNN.js`，渲染正文、检查题、实验入口、上一/下一章。
- `course/exam.html`：12 题结业检查，独立保存 `ca.exam.v1`。
- `course/progress.html`：读取 `ca.course.v1`，汇总章节/实验/结业成绩，支持 JSON 导入导出、重置和 Markdown 作品集导出。
- `course/assets/course.js` 还负责 `localStorage`、导航、TOC、代码编辑器、主题和“继续学习”推荐。

### 2. 实验层

- `labs/lab.html?lab=<id>` 是统一实验壳；`labs/content/*.js` 提供每项实验的正文、官方工作流和初始化。
- `labs/datalab.html` 是独立的 Data Lab：13 个函数、真实 wasm32 C、规则检查和位/浮点观察。
- `labs/*-harness.js` 是浏览器检查器；它们通过 `c-worker.js` 编译 C，或在 JS 中运行受限模型。
- 每个实验都明确标注 **浏览器模型 / 官方工具** 两种模式；官方分数可粘贴/导入，不冒充浏览器分数。

### 3. 执行与可视化

- `engine/c-worker.js`：模块 Worker，负责 Clang/wasm32 编译、链接、运行和输出回传；Data/Cache/Malloc/Performance 共用。
- `engine/y86-*.js`：Y86-64 汇编器、顺序执行器、五级流水线、HCL 控制子集和官方 trace 回放。
- `engine/x86-assembler.js` + `vendor/x86`：AT&T 风格子集的汇编器、ELF 生成和 Blink 用户态执行；用于教学观察，不是完整 Linux。
- `engine/*-lab.js`：Cache、VM、链接、I/O、HTTP、并发、进程、性能等概念模型。
- 3D 场景由这些模型的状态驱动；`index.html` 中的 3D 场景是**概念示意**，不声称与真实处理器逐周期一致。

## 数据流

```text
课程正文/检查题
   ↓ 用户操作
course.js ── localStorage(ca.course.v1 / ca.exam.v1 / ca.code.*)
   ↓
学习档案 ── JSON / Markdown 作品集

实验页
   ↓ 代码/输入
c-worker (wasm32) 或 JS harness
   ↓ 确定性结果/分数
实验页 ── localStorage(ca.course.v1.labs) ── 作品集
```

## 无构建与部署

- 没有 npm 依赖、打包器或服务端渲染；`python3 -m http.server` 即可。
- `vendor/` 内含 Three.js、browsercc、Blink/WASI 运行时，保证离线可用。
- 大型 VM/官方实验材料不在仓库内；`experiments/*/assets/` 由用户自行准备。
- GitHub Pages 部署是手动的（见 [部署](部署.md)）；VM 功能不适用于纯静态托管。

## 关键边界

- 浏览器 C 目标是 **wasm32-wasi**，不是 x86-64 Linux；Data Lab 的函数语义可以对齐，但官方 `dlc/btest` 的逐字节复刻不在浏览器内。
- Attack/Proxy/Shell/Bomb/Buffer 的浏览器端是模型/子集；官方靶场/进程/网络需要 Linux 实验机。
- 学习分数是本站记录的分数，不等于你所在课程的官方成绩。
