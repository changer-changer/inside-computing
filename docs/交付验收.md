## 2. 实验（10 项，含 Buffer legacy）

| 实验 | 浏览器端 | 官方实验机证据 |
|---|---|---|
| Data | 真实 Clang/wasm32；13 任务自动检查 | `driver.pl` 参考实现 62/62 |
| Bomb | 原创六关 x86-64 训练场 + 进度；官方输入 | 6 关 + secret 全解 |
| Attack | 5 关 payload 模型自动检查；官方输入 | ctarget/rtarget 5 关 Touch/PASS |
| Architecture | Y86 Part A/B/C 浏览器检查 | `sum` 0xcba；iaddq `psim` 构建；Part C `ISA Check`、CPI 1.26 |
| Cache | Part A csim + Part B 转置插桩 | csim 27/27；trans 288/1180/1806，Part B 26/26 |
| Performance | 官方 naive rotate/smooth 相对计时检查 | rotate/smooth 平均加速 10.3×/13.6× |
| Shell | JS 作业控制模型 6 场景检查 | 16 组官方 trace 完成，transcript 结构与参考一致 |
| Malloc | 真实 wasm32 分配器 4 trace + 复用检查 | 完整 11 组 trace 全部 valid，82/100（64 位 mdriver） |
| Proxy | JS 代理模型 5 项检查 | 官方 driver 70/70（端口枚举 shim） |
| Buffer | IA32 5 关 legacy 模型 60/60 | 作为第三版前 legacy 对照，无官方靶场 |

## 5. 边界

- 浏览器端部分实验是模型/子集（Attack/Proxy/Shell/Bomb/Buffer，以及 Malloc/Cache/Performance 的浏览器子集），不是官方二进制逐字节复刻；官方分数以实验机原始工具为准。
- Malloc 完整 trace 的 82/100 跑在宿主 64 位 `mdriver`；实验机工作区缺少完整 trace。
- Proxy 70/70 使用 `/proc/net/tcp` 端口 shim 替代缺失的 `netstat`；代理转发/缓存/并发检查本身是官方 driver 的测试。
- 这些是环境或边界说明，不改变课程、实验入口、评分记录与导出链路的可用性。
