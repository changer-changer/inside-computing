# 快速开始

## 1. 环境

- Python 3.9+（静态 HTTP 服务；可选 VM 脚本也用它）
- Node 20+（只用于跑测试，不参与页面构建）
- 现代浏览器：Chrome/Edge/Firefox/Safari 近期版本；3D 场景需要 WebGL
- 可选：macOS + UTM，用于官方 Linux 实验机（bomb/attack/shell/proxy 等）

不需要 npm install、打包器或数据库。

## 2. 启动

```sh
git clone https://github.com/changer-changer/inside-computing.git
cd inside-computing
python3 -m http.server 8000
```

打开 <http://127.0.0.1:8000/>。

macOS 也可双击 `打开学习实验室.command`，它使用固定地址
`http://127.0.0.1:8765/` 并打开首页。

**不要直接双击 `index.html`。** ES Modules、Worker 和 wasm 资源需要通过 HTTP
加载，`file://` 会失败。

## 3. 第一次走一遍

1. 首页 → **完整课程** → 第 1 章。
2. 每章读完检查题，点“标记本章完成”。
3. 首页“继续学习”会自动跳到下一章/下一实验/结业检查。
4. 打开一个实验页，先读“浏览器端 / 官方实验机”的说明：
   - Data Lab 直接在浏览器编译 C；
   - 其他实验可先用模型工作台，再去 Linux 实验机跑官方工具；
   - 官方结果可粘贴回实验页。
5. 打开 [学习档案](../course/progress.html)，导出进度 JSON 或 Markdown 作品集。
6. 做 [结业检查](../course/exam.html) 的 12 道题。

## 4. 运行测试

```sh
npm test
# 等价于
node --test tests/*.test.js
```

当前 48 项 Node 测试通过。Python 语法检查：

```sh
python3 -m compileall -q server experiments tests
```

## 5. 可选：Linux 实验机

官方实验机需要你自行准备以下**不随仓库分发**的资产：

- UTM.app（或通过 `OPEN3D_UTM_APP` 指定）
- Debian 12 genericcloud x86-64 qcow2
- 持久工作区 `student-workspace.qcow2`
- 从 [CS:APP 官方自学页面](https://csapp.cs.cmu.edu/3e/labs.html) 取得的实验原包

把资产放到 `experiments/native-linux/assets/`，按
[`experiments/native-linux/README.md`](../experiments/native-linux/README.md)
和 [资产与第三方](资产与第三方.md) 准备。VM 默认不联网、不挂载宿主目录；
`--network` 只用于安装工具，不应运行不可信程序。

## 6. 常见问题

**页面空白/模块加载失败**

- 确认用 `http://`，不是 `file://`。
- 看浏览器控制台；`vendor/three` 和 `vendor/browsercc` 是否完整。
- 3D 场景无 WebGL 时会显示降级页面；课程/实验页仍可用。

**Data Lab 编译失败**

- 需要 `vendor/browsercc`、`vendor/wasi` 与 `engine/c-worker.js`。
- 看页面控制台的 Worker/编译错误；首次加载 wasm 需要一点时间。

**官方实验机连不上**

- 需要本机 UTM、Debian 镜像与工作区；不是所有平台都支持。
- 先确认 `experiments/native-linux/assets/` 路径；不要在公开仓库提交这些文件。
- 终端桥只绑定本机，不要把端口暴露到公网。

**进度/代码会丢吗**

- 保存在当前浏览器的 `localStorage`；换设备、清理浏览器或隐私模式会丢。
- 用学习档案的“导出进度 JSON”和“导出学习作品集”备份。
