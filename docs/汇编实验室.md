# Y86-64 汇编实验室

点击页面右上角“写汇编”，输入源码，选择“编译并装载”，再选择“单步”或“运行”。修改源码后必须重新编译；“复位”重新装载上次编译的程序。每次点击“运行”最多执行 1000 条，未停止时可继续运行。

源码被编码成机器字节，由项目内的 Y86-64 顺序解释器执行；寄存器、条件码、内存和 3D 中的 PC、%rax、%rbx 来自同一执行器。3D 对象是概念模型，不是硬件仿真或宿主机执行。内存固定为 4096 字节，从 PC 0 开始；程序没有操作系统、系统调用或外部 I/O。

支持寄存器 `%rax`、`%rcx`、`%rdx`、`%rbx`、`%rsp`、`%rbp`、`%rsi`、`%rdi`、`%r8`–`%r14`。支持 `halt`、`nop`、`rrmovq`、条件传送 `cmovle/cmovl/cmove/cmovne/cmovge/cmovg`、`irmovq`、`rmmovq`、`mrmovq`、`addq/subq/andq/xorq`、`jmp/jle/jl/je/jne/jge/jg`、`call`、`ret`、`pushq`、`popq`。支持标签、`#` 注释和 `.pos`、`.align`、`.quad`、`.byte`；`.pos` 和 `.align` 当前只接受数字。数值支持十进制或十六进制，内存操作使用 `位移(%寄存器)`。

例如，以下原创程序累加 3 + 2 + 1：

```asm
irmovq $3, %rcx
irmovq $1, %rbx
xorq %rax, %rax
loop: addq %rcx, %rax
      subq %rbx, %rcx
      jne loop
halt
```

运行结束时，`%rax` 为 6。对于包含 `call`、`pushq` 的程序，应先将 `%rsp` 初始化到合法内存范围内，例如 `irmovq $0x200, %rsp`。

本工具并非 x86-64 汇编器，也不是完整的官方 YAS/YIS 兼容实现；不支持任意 x86-64 指令、系统调用或所有 YAS 表达式。已验证示例和部分边界，但还没有与官方工具进行系统性差分测试。遇到不支持的语法会显示错误，不会把旧程序当成新源码执行。

## 模拟器命令行

在汇编实验室点击“打开命令行终端”，输入 `help` 查看所有命令。这个终端与按钮共享同一模拟器状态；它不是系统 shell，不能运行系统命令、C 编译器或访问本机文件。

- `load`：编译并装载编辑器中的源码。
- `step` 或 `step 3`：执行一条或指定数量的指令。
- `run`：运行至停止或最多 1000 条；`run 50` 可指定上限。
- `regs`、`regs %rax`：查看全部或单个寄存器；`set %rax 5` 修改寄存器。
- `mem 0x300 16`：查看模拟内存；`write 0x300 0xab` 修改一个字节。
- `reset`：恢复已编译程序及已装入的样例；`grade` 检查选中的原创作业；`clear` 清屏。

按上下方向键可查找本次会话中的历史命令。修改源码后，须再次 `load` 才能执行。修改内存中的代码字节后，源码行映射不会自动更新。若程序已停止，请先 `reset` 再执行。

## 3D 显示器

打开命令行时，画面会聚焦到 3D 显示器，并把命令和输出同步显示在屏幕纹理上。输入和无障碍文本仍在侧边终端中；点击“查看 3D 屏幕”可重新聚焦。显示器位于主机外的桌面上，前方是键盘；聚焦时保留主机和桌面的空间关系，并暂时收起部件标签。

屏幕内容由页面把 Y86-64 模拟器终端的文本同步到 3D 纹理，并非 Y86 程序通过显卡、操作系统或物理显示器输出。原 DEEP-16 的文本显存仍是另一套教学模拟；退出汇编实验室后恢复该显示内容。

## iaddq 与流水线

可以使用 `iaddq $-6, %rax`：把立即数加到寄存器，更新零、符号和溢出条件码。顺序执行器支持该指令；基础 PIPE 不支持，需要在流水线面板勾选“启用 iaddq 扩展处理器”并重新装载。这个选项只切换预设模型。也可在控制规则面板修改十二条 HCL 子集规则，勾选自定义控制并重新装入程序，再观察控制信号、寄存器和条件码。可以修改加载后使用、返回等待和分支恢复的暂停与气泡规则；转发和其余控制仍固定。

## 数组复制与周期

在“数组复制与流水线优化”中载入模板，编写 `ncopy`，然后选择流水线配置并检查。完成后可比较各长度的周期和平均 CPE；修改代码或处理器配置后需要重新检查。项目使用自己的测试数据，结果不是官方评分。若想逐周期观察具体程序，可自行编写调用驱动并装入上方流水线。

选择“载入 4 个元素并观察”，会用编辑器中的 `ncopy` 构造调用程序。三维画面显示五级流水线以及源、目标数组；青色和橙色分别标出当前周期实际完成的读取和写入。面板同步列出地址、值与结束状态。可用“复制实验下一周期”逐步执行，修改源码或控制规则后需重新载入。
