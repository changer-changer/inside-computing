# 课程配套作业

> **状态说明**：本文包含早期开发记录，其中“尚未完成”的描述可能已过时；当前已交付范围、官方复验与边界以 [交付验收](交付验收.md)、[README](../README.md) 和 [官方实验机验证记录](官方实验机验证记录.md) 为准。


在 3D 首页点“写汇编”，选择原创配套作业，然后载入初始代码、编写并编译。可以装入一组样例输入，在 3D 模拟器中单步观察；“检查作业”会另外运行多组输入，并报告通过数量与首个失败原因。作业检查不会更改当前观察中的机器状态。程序每组最多执行 512 条指令；程序陷入死循环或异常会被判为未通过。

当前有七道原创 Y86-64 练习：按位异或、两个 64 位数相加、有符号整数比较、使用栈交换数值、函数调用加法、内存存取、遍历数组求和。它们服务于第 2–4 章的部分主题，不能替代 CS:APP 官方作业。

检查使用有限的固定测试集。所有测试通过只能说明该提交通过了当前测试，不证明对所有输入都正确；程序必须正常执行 halt。要求使用的指令在实际运行轨迹中检查。样例输入也可以装载到可见模拟器中；复位时会恢复该样例。

[CS:APP 官方实验说明](https://csapp.cs.cmu.edu/3e/labs.html)涵盖 Data、Bomb、Attack、Architecture、Cache、Shell、Malloc、Proxy 等实验。它们还需要各自的程序环境、数据、测试和授权审核；目前尚未完整接入。更详细状态见 `CSAPP课程与实验对照.md`。
