公开仓库刻意**不包含**体积大或需要单独授权的资产。这样仓库可克隆、可审阅，也不会把官方课程材料或 VM 镜像当作 MIT/CC BY-SA 内容再分发。

| CS:APP 官方实验包（Data/Bomb/Attack/Architecture/Cache/Performance/Shell/Malloc/Proxy） | 官方材料有各自授权；仓库不分发答案/原包 | 从 [CS:APP 官方自学页面](https://csapp.cs.cmu.edu/3e/labs.html) 取得；按 `experiments/native-linux/labs-manifest.json` 校验；`prepare_labs.py` 可下载校验到本地 |
| UTM.app、Debian qcow2、student-workspace.qcow2 | 体积大、第三方运行时、可能含个人作业 | 见 `experiments/native-linux/README.md`；UTM 可用 `OPEN3D_UTM_APP` 指定 |
| QEMU-Wasm 内核/rootfs（约 142 MiB） | 上游构建、再分发条件未审计；浏览器试验未验收 | `python3 experiments/browser-linux/prepare.py`（按 manifest 固定 URL/SHA-256） |
| 参考答案、个人作业、备份 | 学术诚信与隐私 | 不提交；`.gitignore` 已排除本地备份/答案目录之外的资产 |
| 含个人信息的截图/终端日志 | 隐私 | 提交前打码/删去用户名、路径、令牌 |

## 官方实验机的准备顺序

1. 准备 UTM + Debian 12 genericcloud x86-64 qcow2（或使用 `prepare.py` 的固定来源）。
2. 运行 `experiments/native-linux/prepare_labs.py` 取得并校验官方原包；不要把它们放进 git。
3. 启动 VM，按 `experiments/native-linux/README.md` 安装工具、导入材料、`sync` 后退出。
4. 网页入口默认不联网；`--network` 仅用于工具准备，不是安全隔离。

## 再分发检查

- 不要把官方实验答案、`验证参考答案`、个人作业或含隐私的 qcow2 上传。
- 不要把 UTM/Debian/QEMU-Wasm 构建产物直接塞进公开仓库；如确需分发，单独评估许可与体积，优先 Releases/对象存储并附哈希。
- 若修改 `vendor/` 中的第三方文件，保留原 notices 与 `PROVENANCE.md`，并在 PR 说明修改。
- 课程文字/截图采用 CC BY-SA 4.0；代码采用 MIT；第三方保持原许可。
